# SLAB — a to-do list

Modernist, blunt, pink. Charcoal + hot-pink design; works on phone and laptop.

## Features
- **Tasks** — add, edit (inline), complete, delete; categories, priority, due dates, overdue flag
- **Find** — search, filter by status / category / priority, sort by newest / due / priority
- **Progress** — completion %, day streak, 7-day completions chart
- **Panels** — Focus (top 3), Notes, Remember. All saved in your browser (localStorage)

## Run
```bash
npm install
npm run dev
npm test && npm run build
```
